# Posit(8,1) Multiplier in VHDL

An 8-bit Posit multiplier (`es = 1`) implemented in VHDL for FPGA-based arithmetic research at **ProtoFPGA — Universidade Federal de Santa Catarina (UFSC)**.

The design includes Posit decoding, sign and exponent processing, mantissa multiplication, normalization, packing, rounding, and special-value handling.

## Architecture

The multiplier is implemented as a combinational datapath composed of seven VHDL modules.

| Module | Description |
|---|---|
| `decoder_posit` | Extracts the sign, regime, exponent, and fraction |
| `sign_and_exponent_PU` | Computes the result sign, regime, and exponent |
| `mantissa_multiplier` | Multiplies two mantissas with implicit leading bits |
| `normalization` | Normalizes the product and preserves discarded precision |
| `posit_component_packing` | Reconstructs the Posit representation, including saturation |
| `posit_rounding` | Applies round-to-nearest, ties-to-even, and the result sign |
| `posit_multiplier_top` | Integrates the modules and handles zero and NaR |

## Functional Verification

The complete multiplier was verified using **GHDL 6.0.0** and **Python 3.12.6**.

An independent Python reference model generates the expected outputs for all possible operand pairs. These are compared against the VHDL implementation.

| Metric | Result |
|---|---:|
| Operand width | 8 bits |
| Exponent size (`es`) | 1 |
| Total combinations | **65,536** |
| Correct results | **65,536** |
| Mismatches | **0** |
| Operand-pair coverage | **100%** |

The tests cover positive and negative values, zero, NaR, rounding, underflow, overflow, and representable extremes.

## FPGA Implementation

The complete Posit multiplier was synthesized, placed, and routed using **Vivado 2026.1**.

The circuit was measured using a separate register-to-register wrapper, with out-of-context implementation and a 10 ns clock constraint.

| Parameter | Configuration |
|---|---|
| FPGA | Xilinx Virtex-7 `xc7vx485tffg1157-1` |
| Arithmetic format | Posit(8,1) |
| Design | Combinational |
| Measurement | Registered input/output wrapper |
| Clock constraint | 10 ns |
| Synthesis mode | Out-of-context |
| Tool | Vivado 2026.1 |

### Resource utilization

## Reproducing the Results

### Requirements

- Python 3
- GHDL 6.0 or compatible VHDL-2008 simulator
- AMD Vivado 2026.1 for FPGA synthesis and implementation

### Functional verification

Generate the reference vectors:

```bash
python verification/posit_reference.py
```

From the repository root, compile the RTL modules in dependency order:

```bash
ghdl -a --std=08 rtl/decoder_posit.vhd
ghdl -a --std=08 rtl/sign_and_exponent_PU.vhd
ghdl -a --std=08 rtl/mantissa_multiplier.vhd
ghdl -a --std=08 rtl/normalization.vhd
ghdl -a --std=08 rtl/posit_component_packing.vhd
ghdl -a --std=08 rtl/posit_rounding.vhd
ghdl -a --std=08 rtl/posit_multiplier_top.vhd

ghdl -a --std=08 verification/tb/tb_posit_exhaustive.vhd
ghdl -e --std=08 tb_posit_exhaustive
ghdl -r --std=08 tb_posit_exhaustive
```

Expected result:

```text
TOTAL=65536 CORRECT=65536 ERRORS=0
```

### Synthesis and implementation

The automated Vivado scripts are stored in `vivado/synth/`.

Run `build.tcl` using Vivado Tcl mode to reproduce the implementation and generate the resource-utilization, timing, critical-path, and power reports.

The implementation uses the same VHDL arithmetic unit as the functional verification.

## Limitations

- The multiplier currently supports the fixed Posit(8,1) format.
- The core is combinational, without internal pipeline registers.
- The maximum frequency depends on the FPGA, synthesis settings, and placement/routing.
- Power values are estimates and were not measured on physical hardware.
